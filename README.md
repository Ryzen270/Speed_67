## ¿Qué es el menú? ¿Qué son los scripts? ¿Qué son los hacks?

- Menú: una interfaz (a menudo en forma de script o módulo) que centraliza opciones y funciones. En este contexto, el menú permite activar/desactivar scripts, ajustar parámetros y ejecutar acciones desde un punto único.

- Scripts: pequeños programas o fragmentos de código que automatizan tareas. Pueden servir para mejorar la productividad, crear prototipos o demostrar conceptos. Los scripts incluidos suelen estar escritos en lenguajes de scripting comunes y están pensados como ejemplos o utilidades.

- Hacks: este término se usa en la comunidad para referirse a modificaciones o extensiones no oficiales. "Hack" no siempre implica actividad maliciosa; muchas veces se refiere a tweak, mod o parche que altera comportamientos por motivos experimentales o de personalización. Sin embargo, hay que distinguir entre:
  - Modificaciones experimentales y educativas (aceptables cuando se hacen en entornos controlados y con permiso).
  - Uso para vulnerar sistemas, explotar servicios o realizar acciones ilegales (no aceptado ni soportado en este repositorio).
